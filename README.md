One funny passive-aggressive note that a smart fridge leaves for its owner: a single line, dry, petty and specific, about the milk that expired on Tuesday and the 2 a.m. door-opening habit. The program writes the note to `/output/entry.txt` and reads it back to prove it landed byte for byte.

## Run it

```sh
python3 main.py
```
